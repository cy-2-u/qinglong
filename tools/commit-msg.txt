feat(sched): defer chain - 60s catch-up task runs only the leftovers

Budget exhaustion used to punt leftovers to the next scheduled run (a
day later for daily checkins - a lost day of points; monthly renewals
churned through skip-scans). Scripts now return { defer: params } and
the runner idempotently maintains ONE (patch-name) temp task 60s out
holding only the unprocessed set (glados: remaining cookies joined;
dnshe: only_ids filter), self-deleting when nothing remains. User-
visible and cancellable. Zero-progress runs never spawn a chain.
scheduler.runTask re-arms afterwards so the alarm snaps onto the
catch-up run. Contract: result.defer IS the params object.
