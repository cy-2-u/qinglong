fix: remove running short-circuit from manual run

Under the single-flight queue, when a manual run's turn arrives any
genuinely running task has already finalized - so a running status seen
there can only be an isolate crash leftover. The short-circuit never
protected anything; it just blocked manual recovery (UI said "already
running" while the status was a corpse). Manual run now overwrites and
doubles as crash recovery; frontend drop the matching toast branch.
