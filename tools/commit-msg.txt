fix: API contract - tasks always return params as an object

D1 stores params as a JSON string (TEXT column); the endpoints returned
rows as-is, so live mode sent params as a string and the editor's
Object.keys() exploded it into one param row per character (the
"{" "c" "o" "o" "k" "i" "e"... rows). Mock mode returned real objects
so the contract mismatch never surfaced locally.

- toClientTask() parses params (fallback {} on bad JSON) and is applied
  to every endpoint that returns a task row (list/create/update/patch)
- runner already parsed params defensively, unaffected
