fix: real dark mode + qtip styles that never shipped

Dark mode:
- dark class lived on <body> but the CSS vars are defined at :root;
  custom properties don't inherit upwards, so the html canvas kept the
  light cream background and short pages showed a light bottom half.
  Class moved to documentElement, selectors body.dark -> html.dark

Tooltips:
- the .qtip stylesheet block was silently lost in a failed find/replace
  last round - tooltips rendered as unstyled text appended at the end
  of the document (bottom-left). Styles added (light + dark variants)

Cache:
- index.html now references assets with ?v= version param so deploys
  reach browsers without hard refresh
